Deployed via Terraform + GitHub Actions

Static Site on AWS, Shipped by CI/CD

This page is served from a private S3 bucket through CloudFront. Every part of the infrastructure below was provisioned by Terraform, and every deploy of this page happens automatically on push to main.

Infrastructure (Terraform)

S3 (private, OAC-locked) → CloudFront (HTTPS, custom error pages) → optional Route 53 + ACM for a custom domain. A GitHub OIDC role is also provisioned so the pipeline never touches long-lived AWS keys.

Amazon S3 CloudFront ACM Route 53 IAM OIDC

Pipeline (GitHub Actions)

Two workflows: one plans/applies Terraform changes on pull requests and merges to main; the other syncs this site/ folder to S3 and invalidates the CloudFront cache whenever site content changes.

terraform fmt / validate terraform plan on PR terraform apply on merge aws s3 sync CloudFront invalidation
